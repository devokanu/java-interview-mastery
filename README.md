# Java Interview Mastery

Senior Java/Spring, backend architecture, and banking-domain interview preparation workspace.

Main working language: Turkish.

English is used alongside Turkish for interview questions, answers, screening tests, and technical interview practice.

## Quick Start For Any AI Session

1. Read [AI_SESSION_CONTEXT.md](AI_SESSION_CONTEXT.md).
2. Read [rules/STUDY_RULES.md](rules/STUDY_RULES.md).
3. Check [progress/TOPIC_TRACKER.md](progress/TOPIC_TRACKER.md).
4. Animation [animations/index.html](animations/index.html).
5. Continue from the current topic and do not skip required outputs.
